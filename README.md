A one-line error message from a kitchen toaster with a stuck lever — deadpan, apologetic, and holding breakfast hostage until you press it. The program writes the winning line to `entry.txt`, deterministically, every run.

> Lever stuck. I am holding your breakfast hostage. Press me.

The line is 59 characters (59 bytes): short enough to fit a real appliance display, with the joke landing on a single read.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
